# Матриця трасування вимог

Матриця показує зв'язок **багато-до-багатьох** між функціональними вимогами, сценаріями Gherkin та варіантами використання Wishlist Service (одна вимога може покриватися кількома сценаріями/UC; один сценарій або UC - кількома вимогами). Нефункціональні вимоги зібрані окремо: вони обмежують спосіб виконання функціональних вимог. Окремий сценарій має NFR-04: SC-12.

| Вимога | Сценарії | Варіанти використання | Покриття |
|---|---|---|---|
| REQ-01 — Створення списку | SC-01 | UC-01 | Покрито |
| REQ-02 — Обмеження доступу до приватного списку | SC-02 | UC-04 | Покрито |
| REQ-03 — Перегляд публічного списку | SC-08 | UC-04 | Покрито |
| REQ-04 — Додавання товару | SC-09 | UC-03 | Покрито |
| REQ-05 — Бронювання доступного товару | SC-03, SC-12 | UC-05, CheckItem (`<<include>>`) | Покрито |
| REQ-06 — Заборона бронювання власного товару | SC-04 | UC-05, CheckItem (`<<include>>`) | Покрито |
| REQ-07 — Скасування бронювання | SC-05 | UC-06 | Покрито |
| REQ-08 — Позначення товару завершеним | SC-06 | UC-07 | Покрито |
| REQ-09 — Скасування бронювання завершеного товару | SC-06 | UC-07, CancelOnComplete (`<<extend>>`) | Покрито |
| REQ-10 — Приховування особи того, хто забронював товар | SC-10 | UC-02 | Покрито |
| REQ-11 — Автентифікація користувача | SC-11 | UC-08 | Покрито частково |
| REQ-12 — Надсилання запрошення | SC-07 | UC-09, CheckPublic (`<<include>>`) | Покрито |

### Непокриті вимоги / сценарії

| Вимога / ситуація | Статус | Пояснення |
|---|---|---|
| REQ-11 (невдалий вхід) | Непокрито | SC-11 перевіряє лише успішну автентифікацію. |
| Недоступність Email Service (REQ-12, NFR-06) | Непокрито | NFR-06 фіксує повідомлення власника і заборону змінювати список. SC-07 описує лише успішну передачу листа. |

### Нефункціональні вимоги

Таблиця показує, яку функціональну поведінку обмежує кожна нефункціональна вимога. Для NFR-04 це перевіряє сценарій SC-12.

| Вимога | Обмежує | Перевірка |
|---|---|---|
| NFR-01 — Час відповіді | REQ-03, REQ-05 | Вимір часу відповіді для 95% запитів при до 100 сесіях |
| NFR-02 — Доступність | UC-04, UC-08 | Частка доступності за календарний місяць |
| NFR-03 — Захист каналу та паролів | REQ-11 | Перевірка TLS і збереження лише хешу пароля |
| NFR-04 — Ізоляція одночасного бронювання | REQ-05, SC-12 | Один запис `Reservation` на товар, другий запит відхилено |
| NFR-05 — Доступ лише після автентифікації | REQ-01, REQ-04, REQ-05, REQ-07, REQ-08, REQ-11 | Відхилення операцій без автентифікації |
| NFR-06 — Недоступність Email Service | REQ-12 | Повідомлення про помилку без зміни списку |
| NFR-07 — Обсяг списку | REQ-03, NFR-01 | Відображення списку до 200 товарів у межах NFR-01 |
